# Forge Curriculum Structure
Version: 2.0

# Philosophy

Forge is not a collection of tutorials.

It is a structured engineering academy.

Every lesson exists for a reason.

Every concept prepares the learner for the next concept.

Nothing is taught out of order.

A learner should be able to start with zero frontend knowledge and graduate as a Senior Frontend Engineer.

# Success Criteria

The curriculum should feel like a university-level computer science program focused entirely on frontend engineering.

The learner should never feel lost.

Navigation should always answer:

- Where am I?
- What have I completed?
- What comes next?
- Why am I learning this now?
- How does this connect to previous topics?

Every lesson must build naturally on the previous lesson, creating one continuous journey from beginner to Senior Frontend Engineer.
