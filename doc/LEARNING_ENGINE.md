# Forge Learning Engine
Version: 2.0

---

# Philosophy

Forge is not a video platform.

Forge is not a documentation website.

Forge is not a collection of tutorials.

Forge is a learning engine.

Every action should move the learner closer to becoming a Senior Frontend Engineer.

Learning must feel intentional, measurable, adaptive, and rewarding.

---

---

# Adaptive Learning

If a learner repeatedly fails:

Pause progression.

Recommend prerequisite review.

Recommend additional practice.

Recommend AI Mentor help.

Recommend debugging exercises.

Learning adapts without frustrating the learner.

# AI Mentor Integration

AI is a guide.

Never the teacher.

The AI Mentor should:

Review code.

Guide debugging.

Never skip the curriculum.

Use Socratic questioning whenever possible.
